# Student Performance Analysis System

##  Project Description

The **Student Performance Analysis System** is a Python-based project designed to analyze student academic performance. It processes student marks, calculates total and average marks, identifies Pass/Fail status, assigns grades, and finds the top-performing student.

The project also uses data visualization to present student performance in an easy-to-understand format.

---

## Objectives

* To analyze student academic performance.
* To calculate total and average marks.
* To identify Pass and Fail students.
* To assign grades based on average marks.
* To find the top-performing student.
* To calculate subject-wise average marks.
* To visualize student performance using charts.
* To understand practical use of Python and data analysis.

---

##  Features

*  Student information management
*  Total marks calculation
*  Average marks calculation
*  Pass/Fail classification

