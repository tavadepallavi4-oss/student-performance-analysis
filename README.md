# Student Performance Analysis

## Project Overview

Student Performance Analysis is a Python project that analyzes student marks and generates useful performance information.

## Objectives

- Calculate total marks
- Calculate average marks
- Find Pass or Fail status
- Assign grades
- Find the top student
- Calculate subject averages
- Generate a performance chart

## Technologies Used

- Python
- Pandas
- Matplotlib

## Features

- Student marks analysis
- Total and average calculation
- Pass/Fail classification
- Grade calculation
- Top student identification
- Data visualization

## Dataset

The dataset contains student information and marks for:

- Math
- Science
- English
- Computer
